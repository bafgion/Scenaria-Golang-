# Настройки

**Файл → Настройки…** (или палитра команд). Вкладки:

## Интерфейс

- Тема: системная / светлая / тёмная
- Компактная панель инструментов, ширина каталога
- Высота нижней панели, панели шагов
- Превью сценария
- Проверка обновлений при старте

**Применить** — оставить окно открытым; **OK** — сохранить и закрыть. **Сброс** — значения по умолчанию.

## Редактор

- Шрифт, табуляция, перенос строк
- Minimap, номера строк
- Формат при сохранении
- Inlay hints, code lens
- Порог «большого файла»

## Запись

- Таймаут простоя, фильтры
- Приоритеты селекторов
- Нормализация шагов после записи

## Селекторы

- Браузер для проверки
- Ожидание навигации
- Политика повторов

## Плагины

- Каталоги, список включённых
- Установка / удаление

Настройки: `.scenaria/settings.json` (проект) и профиль пользователя (глобальные параметры IDE).
