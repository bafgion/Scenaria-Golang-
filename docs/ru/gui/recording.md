# Запись сценариев

Запись действий в браузере в шаги `.feature` через Playwright.

## Запуск записи (IDE)

1. Откройте или создайте `.feature` (куда писать шаги)
2. **Запись → Начать запись…**
3. URL, параметры, таймаут простоя
4. **Начать** — открывается браузер, шаги добавляются в сценарий

Во время записи:

| Элемент | Действие |
|---------|----------|
| **Пауза / Продолжить** | Временно не записывать события |
| **Отменить шаг** | Удалить последнюю строку из редактора |
| **Стоп** | Завершить, нормализовать шаги |

Панель: фильтр шума, только ссылки, наведение, **headless** (перезапуск окна с тем же URL).

## Что записывается

- Переходы (`goto`), клики, ввод, select, checkbox, загрузка файлов
- Клавиши, скролл, drag-and-drop, наведение (опция)
- Подпись на canvas

Селекторы: testid → id → aria → label → text. См. [Селекторы](../authoring/selectors.md).

## Указать элемент (picker)

Вставка селектора без полной записи клика — с панели браузера или во время записи.

## После записи

Баннер может предложить **просмотр diff** — сравнение текста до и после.

## HTTP Auth

**HTTP Auth…** перед записью — учётные данные для сессии.

## TestClient

Сохранение сессии: **TestClient…** / **Сохранить сессию браузера…**

```gherkin
Контекст:
  Дано я подключаю TestClient "DemoUser"
```

## CLI

```bash
scenaria record --live --url https://example.com --output recorded.feature --idle 30
```

| Флаг | Описание |
|------|----------|
| `--live` | Живая запись |
| `--url` | Стартовый URL |
| `--output` | Путь к `.feature` |
| `--idle N` | Стоп после N сек без событий (по умолчанию 30) |
| `--headless` | Без окна браузера |

## Безопасность

Скрипты записи — только для **ваших** стендов; пути ограничены корнем проекта.
