# Результаты и отчёты

## Вкладки нижней панели

| Вкладка | Содержимое |
|---------|------------|
| **Журнал** | Лог: проверка, запуск, запись |
| **Результаты** | Статусы сценариев последнего прогона |
| **Проверка** | Список проблем проверки в браузере |
| **Ошибка** | Последняя критическая ошибка, переход к строке |

Клик по упавшему сценарию — открыть файл и перейти к шагу.

## Артефакты

По умолчанию в `.scenaria/`:

| Артефакт | Включение | Путь |
|----------|-----------|------|
| `run_status.json` | Всегда (GUI) | `.scenaria/` |
| JUnit | Диалог / `--junit` | настраивается |
| HTML | `--html` | `.scenaria/report.html` |
| Allure | диалог / `--allure` | `.scenaria/allure-results/` |
| Trace | `--trace` | `.scenaria/traces/` |
| Video | `--video` | `.scenaria/videos/` |

## Allure

1. Включить **Allure** в параметрах запуска
2. После прогона — **Открыть Allure** (папка в проводнике)
3. Локально: `allure serve .scenaria/allure-results` ([Allure CLI](https://docs.qameta.io/allure/))

При падении — вложения: скриншот, trace, video.

## Trace viewer

При падении с включённым trace — **Открыть trace** (если установлен Playwright CLI).

## Flaky

Панель результатов помечает нестабильные сценарии; **Прогон flaky 3×** — три повтора.

## История запусков

**Вид → История запусков…** — прошлые прогоны, повтор упавших.
