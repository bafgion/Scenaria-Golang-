# Запуск тестов

## Dry-run и Playwright

| Режим | Браузер | Когда |
|-------|---------|-------|
| **Dry-run** | Нет | Разбор шагов, проверка DSL |
| **Playwright** | Да | Реальный UI-тест |

**Ctrl+Enter** — запуск (первый раз — диалог). **Запуск → Dry-run** — без браузера.

## Диалог запуска

- Сценарий или весь файл
- Тег, переменные (`KEY=value`)
- Браузер, workers, slow-mo, base URL
- JUnit, HTML, Allure, trace, video
- Частичный прогон: с шага / до шага

Галочка «не показывать снова» — прямой запуск; сброс через **Запустить…**.

## Проверка

**Запуск → Проверить…**

| Режим | Что проверяет |
|-------|----------------|
| Только синтаксис | Gherkin, известные шаги |
| В браузере | Видимость селекторов на странице |
| Текущий / проект | Область |

Результат — вкладки **Проверка** или **Журнал**.

## Пакетный запуск

Выбор нескольких feature в каталоге → **Запуск**.

## Во время прогона

- Строка состояния и прогресс
- **Журнал** — поток лога
- **Ctrl+Shift+R** — остановка

## Частичный запуск

Code lens или контекстное меню: сценарий, с строки, до строки.

## CLI

```bash
scenaria run ./features --dry-run
scenaria run ./features --tag smoke --headed
```

См. [CLI](../cli/reference.md).
