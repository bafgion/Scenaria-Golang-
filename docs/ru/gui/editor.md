# Редактор

В Scenaria используется **Monaco** с языком `scenaria-feature` для русского Gherkin.

![Редактор Gherkin](../../images/gui-main-ru.png)

## Вкладки и файлы

- Каждый `.feature` — отдельная вкладка; несохранённые изменения отмечены точкой
- **Новый сценарий** — вкладка из шаблона
- Закрытие изменённой вкладки — запрос сохранения
- После перезапуска восстанавливаются вкладки и позиция курсора

## Подсказки и сниппеты

| Сочетание | Действие |
|-----------|----------|
| **Ctrl+Space** | Дополнение шагов на текущей строке |
| **Палитра сниппетов** | Вставка шагов из каталога |

Учитывается контекст (`Если`, строки таблицы и т.д.).

## Справка по шагам

- **Наведение** на строку шага — краткая подсказка и ошибки
- **F1** — полный каталог по категориям
- **Inlay hints** — предупреждения в полях строк

## Форматирование и навигация

| Сочетание | Действие |
|-----------|----------|
| Shift+Alt+F | Форматировать документ |
| Ctrl+Shift+O | Перейти к символу (сценарии, правила) |
| Ctrl+F / Ctrl+H | Поиск / замена |
| Сворачивание | Блоки `Если`, `Повторяю`, `Пока`, `Для каждого` |

**Формат при сохранении** — в **Настройки → Редактор**.

## Превью

**Вид → Превью** — read-only представление feature (с debounce). На файлах ≥2000 строк отключаются minimap, code lens и inlay для скорости.

## Подсказки сценария

При сохранении или проверке — советы по шагам и отступам. Автоисправление — в настройках.

## Code lens

Над сценариями: запуск, dry-run, запуск до строки.
