# Обучающий тур

В Scenaria есть **интерактивный тур из 8 шагов** для новых пользователей: подсветка областей интерфейса и ожидание действия.

## Как запустить

| Когда | Как |
|-------|-----|
| Первый запуск | Тур может начаться автоматически, если обучение не завершено |
| В любой момент | **Справка → Обучение…** (с начала) |

**Пропустить** — закрыть тур; статус сохраняется в настройках.

## Шаги тура

| № | Действие |
|---|----------|
| 1 | Приветствие → **Далее** |
| 2 | **«Открыть примеры сценариев»** на вкладке «Старт» |
| 3 | Выбрать `.feature` в каталоге |
| 4 | Редактор Monaco → **Далее** |
| 5 | **Запуск → Проверить…** → проверка синтаксиса |
| 6 | **Запуск → Dry-run** (подтвердить диалог при первом запуске) |
| 7 | Вкладка **«Журнал»** в нижней панели (нужен явный клик) |
| 8 | Завершение → **Готово** |

Подсветка с затемнением фона. Шаги-действия переключаются автоматически после выполнения.

## Советы

- Если тур мешает кликам — завершите шаг или **Пропустить**
- На шагах проверки и dry-run меню **«Запуск»** остаётся открытым
- После dry-run журнал может открыться сам, но шаг 7 засчитывается только после клика по вкладке **«Журнал»**
- Проверка обновлений откладывается до открытия проекта
