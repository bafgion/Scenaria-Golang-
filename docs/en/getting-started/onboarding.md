# Onboarding tour

Scenaria includes an **8-step interactive tour** for new users. It highlights UI regions and waits until you perform each action.

## Start the tour

| When | How |
|------|-----|
| First launch | Tour may start automatically if onboarding was not completed |
| Any time | **Help → Training…** (restarts from step 1) |

Press **Skip** to dismiss; completion is remembered in settings.

## Tour steps

| # | ID | What you do |
|---|-----|-------------|
| 1 | Welcome | Read intro → **Next** |
| 2 | Open examples | Click **Open example scenarios** on Start tab |
| 3 | Pick feature | Select a `.feature` in the catalog tree |
| 4 | Editor | Read about Monaco → **Next** |
| 5 | Validate | **Run menu → Validate…** → confirm syntax check |
| 6 | Dry-run | **Run menu → Dry-run** (confirm run dialog if shown) |
| 7 | Journal | Click the **Journal** tab in the bottom panel |
| 8 | Finish | Summary → **Done** |

The tour spotlights controls with a dimmed overlay. Action steps auto-advance when the task completes.

## Tips

- If the tour blocks clicks, finish the current step or press **Skip**
- **Validate** and **Dry-run** steps keep the **Run** menu open
- After dry-run, open **Journal** manually — auto-switch to the journal tab does not complete step 7
- Update checks are deferred until a project is open so they do not overlap the tour
