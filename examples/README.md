# Примеры сценариев Scenaria

Готовые `.feature` для первого знакомства. Сайт [example.com](https://example.com) — без логина.

**Полное руководство:** [docs/ru/authoring/examples.md](../docs/ru/authoring/examples.md) · [English](../docs/en/authoring/examples.md)

## Как открыть

1. **«Старт»** → **«Открыть примеры сценариев»**
2. Выберите файл в каталоге → **Запустить тест** (Ctrl+Enter)

Или **Проект → Открыть проект…** → папка `examples`.
